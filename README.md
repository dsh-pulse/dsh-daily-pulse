# dsh-daily-pulse 📡

DSH 插件生态的每日数据脉搏。

## 这是什么？

每天 6:00 / 14:00 / 22:00 三次自动生成 DSH 插件生态报告，涵盖：
- 插件总量增长
- Star 爆发榜
- 新插件推荐（含中文摘要 + 健康分）
- 官方动态
- 沉寂预警

## 数据来源

- GitHub Search API（topic:dsh-plugin）
- npm registry
- dshhub.dev / dsh.so

## 输出

- reports/ — 每日 Markdown 日报
- 自动发布到 GitHub Pages
