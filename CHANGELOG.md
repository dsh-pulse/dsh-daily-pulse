# Changelog

All notable changes to dsh-daily-pulse are documented here. Format follows
[Keep a Changelog](https://keepachangelog.com/) and semantic versioning.

## 0.1.0 - 2026-08-19

First formal release — the full M0→M4 pipeline, live at
https://dsh-pulse.github.io/dsh-daily-pulse since 2026-08-17 (3 snapshots/day).

### Features

- **M0 — Collection pipeline**: incremental snapshots from GitHub + npm; plugin
  totals from the `/topics/dsh-plugin` page (bypassing the Search API 1000-row
  cap, with parse-failure fallback + alert); tag-abuse scoring
  (manifest +2 / `@deepseek-ai/dsh` dependency +2 / topic +1, ≥3 to rank);
  `bootstrap.mjs` one-time top-1000 repo library.
- **M1 — Growth leaderboard + archive + CI**: star-delta growth leaderboard
  (star-index baselines), archive homepage with history curves, 3×/day
  scheduled CI (Beijing 06:00/14:00/22:00) with auto-commit and GitHub Pages,
  design-system tokens v0.2.1.
- **M2 — AI summary + health score**: DeepSeek-generated bilingual daily
  summary (rule fallback without a key); 4-factor ecosystem health score
  (activity 40 + freshness 20 + adoption 20 + diversity 20); CI summarize step.
- **M2b — Fully bilingual reports**: complete zh/en dual files with language
  switcher (`--lang zh|en`, `latest.html` = Chinese entry).
- **M3 — Archive visualization + GEO structured output**: dual-axis chart
  (official stars + plugin totals), 2×2 metric mini-chart matrix with hover,
  npm natural-day download caliber (range API with backfill); structured
  output (`render-structured.mjs`: JSON-LD `Dataset` + clean English body) for
  AI-engine citation.
- **M4 — Open data + category boards + content**: `export.mjs` →
  `reports/data/` (snapshots.csv / latest.csv / leaderboard.csv / latest.json,
  later category-boards.csv / active-board.csv) with a documented data
  dictionary; category boards (Top 10 × 4 dims: stars/growth/activity/newest,
  100-candidate pool); content sections "New Faces (8h)" and "Stale Watch"
  lists; summary moved above the boards (takeaway first).
- **bridge WeChat notify**: local report runs can push the daily digest to
  WeChat via dsh-hermes-bridge (skipped in CI without env).

### Fixes

- collect: raw-fetch tolerance so a single manifest read failure never breaks
  the run.
- M2b: bilingual residue cleanup (brand area / theme toggle / chart captions /
  head description / health-factor notes / `index_en.html` title).
- M3 charts: SVG stretch (removed `preserveAspectRatio="none"`), baseline +
  dual-series dots + date ticks on the dual-axis chart, grid + max/min ticks on
  mini-charts, `--lang=en` argument parsing.
- M3 npm line: weekly flat window → daily downloads + range-API historical
  backfill, then natural-day caliber (stable daily values, no rebase
  conflicts — artifacts regenerated by CI).
